# Ashlink

A private link for a four-digit code. It is drawn as an image, disappears after a timer, then the page moves on. No sign-in.

**Live page:** https://bannon-github.github.io/ashlink/

Enter a code, choose how long it stays up, and where the page should go next. The share link works for anyone who has it. The code is stored in the link itself, not in an account.
