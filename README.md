# Ashlink

A private link for a four-digit code. It is drawn as an image, disappears after a timer, then the page moves on. No sign-in.

**Live page:** https://bannon-github.github.io/ashlink/

Enter a code, choose how long the image stays up, and how long the link itself keeps working. That deadline is a timestamp inside the link. After it passes, the page will not draw the code. No account.
